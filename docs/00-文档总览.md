## 交付原则

- 不使用假数据常驻系统。
- 初始化 SQL 只写入系统必需菜单、权限、字典和配置。
- 发版验收允许创建临时真实数据，但必须带统一前缀并清理。
- 自动化脚本验数据流转，外置 Chrome 可见窗口验页面交互。
- 本项目页面验收禁止使用 Codex 内置浏览器，禁止使用 headless 浏览器。
