# 发版验收与自动化测试说明

## 验收分层

LingNow ERP 发版验收分两层：

1. 自动化脚本验收：验证真实接口、数据库、审批、库存、资金、往来、权限、通知、报表、清理。
2. 外置 Chrome 页面回归：验证登录、菜单、页面、弹窗、按钮、表格、打印预览、通知抽屉、H5 页面。

两层都通过，才算可发版。

## 自动化脚本入口

推荐命令：

```bash
ADMIN_BASE_URL=http://localhost:8090/admin-api \
APP_BASE_URL=http://localhost:8090/app-api \
DB_NAME=lingnow_erp \
DB_USER=root \
MYSQL_PWD='你的MySQL密码' \
node scripts/release-acceptance.mjs
```

兼容入口：

```bash
ADMIN_BASE_URL=http://localhost:8090/admin-api \
APP_BASE_URL=http://localhost:8090/app-api \
DB_NAME=lingnow_erp \
DB_USER=root \
MYSQL_PWD='你的MySQL密码' \
node scripts/acceptance-check.mjs
```

`acceptance-check.mjs` 会转调 `release-acceptance.mjs`。

## 默认环境变量

未显式传入时使用：

```text
ADMIN_BASE_URL=http://localhost:8090/admin-api
APP_BASE_URL=http://localhost:8090/app-api
DB_NAME=lingnow_erp
DB_USER=root
ADMIN_USERNAME=admin
ADMIN_PASSWORD=123456
```

`MYSQL_PWD` 必须传入，否则数据库断言无法执行。

## 自动化覆盖

自动化脚本覆盖 19 条流程：

- 基础资料。
- 进货入库。
- 销售出库。
- 库存不足。
- 销售退货。
- 进货退货。
- 收款单。
- 付款单。
- 库存盘点。
- 审批综合。
- 商品导入导出。
- 单据导出打印。
- 报表。
- 系统配置。
- 权限。
- 数据授权。
- 通知中心。
- 服务监控。
- 移动端/App。

## 页面回归要求

页面回归必须：

- 使用外置 Chrome 可见窗口。
- 不使用 Codex 内置浏览器。
- 不使用 headless 浏览器。
- 先确认当前 URL、端口、页面文案和目标项目一致。
- 最终列出测试 URL、流程、PASS/FAIL、失败原因。

## 下次让 Codex 做 Chrome 回归的标准口令

```text
用外置 Chrome 可见窗口，对当前仓库做发版页面回归。
目标地址：http://localhost:8090
账号：admin / 123456
按 19 条流程测：
1. 管理端登录、菜单、权限
2. 基础资料新增/编辑/查询
3. 进货、销售、退货、收付款、盘点、审批
4. 通知、监控、报表、打印预览
5. H5：http://localhost:8090/h5/
不要用内置浏览器，不要用 headless。
最后按流程列出 PASS/FAIL、失败原因、测试过的 URL。
```

## 通过标准

- 自动化脚本所有流程 PASS。
- 外置 Chrome 页面回归无业务阻断 FAIL。
- 允许说明类 NOTE，例如浏览器扩展无法捕获 Blob 下载事件，但必须有接口验收或人工下载核验补充。
- 测试临时数据已清理，或明确保留原因和前缀。
