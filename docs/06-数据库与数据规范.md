# 数据库与数据规范

## 默认数据库

```text
lingnow_erp
```

## 初始化脚本

```text
backend/sql/init.sql
```

初始化脚本只写入：

- 系统菜单。
- 按钮权限。
- 默认角色和管理员。
- 字典。
- 系统参数。
- ERP 必要配置，例如默认单号规则。

初始化脚本不写入：

- 演示商品。
- 演示客户。
- 演示供应商。
- 演示库存。
- 演示单据。
- 演示资金流水。

## 表分类

### 系统表

- 用户、角色、用户角色。
- 菜单、权限。
- 部门、岗位、字典、参数。
- 文件、日志、通知。

### ERP 基础资料

- 商品分类。
- 单位。
- 品牌。
- 属性。
- 商品。
- 客户。
- 供应商。
- 仓库。
- 账户。
- 代理等级。

### ERP 单据

- 单据主表。
- 单据明细表。
- 财务单据表。
- 库存盘点主表。
- 库存盘点明细表。

### 流水

- 库存流水。
- 资金流水。
- 往来流水。

### 审批与任务

- Warm-Flow 相关表。
- Quartz 任务表。
- Quartz 任务日志表。

## 临时验收数据

自动化验收脚本使用：

```text
ACCEPT_时间戳_
```

页面回归人工测试可使用：

```text
UIREG_时间戳_
```

要求：

- 测试前清理旧临时数据。
- 测试后物理清理临时数据。
- 不允许把临时数据作为系统演示数据长期保留。

## 数据安全要求

- 密码不明文保存。
- `.env` 不提交。
- 数据库连接串、Redis 密码、Token 不写入文档正文。
- 导入导出只使用真实接口，不绕过业务校验。
