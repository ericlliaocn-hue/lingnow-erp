# 部署运维手册

## 默认端口

- Web 网关：`8090`。
- Admin API 容器内部端口：`6060`。
- App API 容器内部端口：`6061`。
- MySQL：按部署环境配置。
- Redis：按部署环境配置。

## 环境要求

- JDK 17+。
- Maven 3.8+。
- Node.js 18+。
- MySQL 8+。
- Redis 7+。
- Docker 和 Docker Compose。

## 构建

后端：

```bash
cd backend
mvn -q -DskipTests package
```

管理端：

```bash
cd admin-ui
npm ci
npm run build
```

H5：

```bash
cd uniapp
npm ci
npm run type-check
npm run build:h5
```

## 数据库初始化

先创建数据库：

```sql
CREATE DATABASE lingnow_erp DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

导入初始化脚本：

```bash
mysql -u root -p lingnow_erp < backend/sql/init.sql
```

## Docker 完整单机模式

完整模式包含 MySQL、Redis、Admin、App、Web：

```bash
cp .env.example .env
```

编辑 `.env`，替换所有 `CHANGE_ME`。

启动：

```bash
docker compose --env-file .env up -d --build
```

停止：

```bash
docker compose --env-file .env down
```

## 宿主机 MySQL/Redis 模式

本地验收推荐此模式，只启动 Admin、App、Web，MySQL/Redis 使用宿主机服务：

```bash
cp .env.example .env
cp docker-compose.host.example.yml docker-compose.host.yml
docker compose --env-file .env -f docker-compose.host.yml up -d --build
```

注意：

- `.env` 不提交。
- `docker-compose.host.yml` 不提交。
- `.env.example` 和 `docker-compose.host.example.yml` 可提交。

## 健康检查

```bash
curl http://localhost:8090/healthz
curl http://localhost:8090/admin-api/welcome
curl http://localhost:8090/app-api/welcome
```

期望都返回 `200`。

- Admin API：`http://localhost:8090/admin-api`
- App API：`http://localhost:8090/app-api`


## 常见运维命令

查看容器：

```bash
docker compose --env-file .env ps
```

查看日志：

```bash
docker compose --env-file .env logs -f admin app web
```

重启服务：

```bash
docker compose --env-file .env restart admin app web
```

宿主机模式：

```bash
docker compose --env-file .env -f docker-compose.host.yml ps
docker compose --env-file .env -f docker-compose.host.yml logs -f admin app web
docker compose --env-file .env -f docker-compose.host.yml restart admin app web
```
