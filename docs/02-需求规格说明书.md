# 需求规格说明书

## 原始需求概述

客户希望实现一套 ERP 系统，核心诉求包括：

- 销售开单、销售退货。
- 商品资料、分类、单位、属性、品牌。
- 进货、进货退货。
- 库存查询、库存盘点、库存预警、批次查询。
- 财务往来、收款、付款、其他收入、其他支出、资金流水。
- 销售、进货、利润、库存、员工绩效等报表。
- 客户、供应商、仓库、系统参数、打印模板、字段设置、单号规则、操作日志、账号权限。
- 权限按菜单、按钮、数据范围控制。
- 单据审批、审核、反审核、库存和资金回滚。
- 新订单/通知语音提醒。
- 地址识别，用于快速拆分姓名、手机号、地区和详细地址。

## 功能范围

### 管理端

- 数据看板。
- 系统管理：用户、角色、菜单、文件。
- 基础设置：部门、岗位、字典、参数、通知公告、职员。
- 日志管理：操作日志、登录日志、错误日志、慢 SQL 日志。
- 系统监控：服务监控、缓存监控、在线用户、实时日志、任务监控。
- 审批中心：待我审批、我发起的、已办审批、流程设计器入口。
- 商品：商品管理、商品分类、单位、品牌、属性。
- ERP 设置：客户、供应商、仓库、账户、代理等级、单号规则、字段设置、打印模板。
- 销售：销售单、新增销售单、销售退货单、新增销售退货。
- 进货：进货单、新增进货单、进货退货单、新增进货退货。
- 库存：库存查询、商品收发明细、库存盘点、新增库存盘点、库存预警。
- 财务：收款、付款、其他收入、其他支出、资金流水、往来流水。
- 报表：销售统计、销售明细、利润、经营利润、热销榜、进货统计、库存余额、应收应付、账户余额、员工业绩、收发汇总、进销存变动、经营汇总。

### 移动端/H5

- 首页。
- 客户。
- 商品。
- 单据。
- 我的。
- 新建单据业务壳。
- 地址识别入口。

移动端 v1 不直接创建正式库存/财务单据，正式开单、审核、库存处理和财务处理优先在管理端完成。

## 非功能需求

- 不允许假数据常驻。
- 关键操作必须走后端真实接口。
- 登录、鉴权、权限、验证码等安全链路不得绕过。
- 审批、库存、资金、往来必须可回滚。
- 页面级验收必须使用外置 Chrome 可见窗口。
- 发版前必须跑自动化验收脚本。
- 数据库初始化只包含必要系统数据，不插入演示 ERP 业务数据。
