# 项目立项说明

## 项目名称

LingNow ERP

## 项目背景

客户最初希望复刻一套轻量 ERP 系统，重点关注销售、商品、进货、库存、财务、报表、基础资料、权限、打印模板、收银、通知提醒等能力。前期参考过多套现有 ERP 系统，并按菜单、页面、按钮、字段、交互、业务规则和权限粒度做过拆解。

后续决定使用 `lingnow-admin` 通用基座作为底座，剔除无关业务模块，保留通用后台能力，再在其上实现 ERP 业务。这样便于后续接单复用基座，同时让 ERP 项目和基座仓库保持独立。

## 项目目标

- 做出一套可交付、可部署、可验收的 ERP v1。
- 管理端覆盖基础资料、商品、销售、进货、库存、财务、报表、审批、通知、权限、监控。
- 移动端先作为业务端/H5 壳，提供首页、客户、商品、单据、我的、新建单据和地址识别入口。
- 接入 Warm-Flow 审批流，支撑单据提交、通过、驳回、撤回、转交和审批记录。
- 提供发版验收自动化脚本，每次发版前能验证 19 条核心流程。
- 提供 Docker 交付方案，默认 Web 入口使用 `8090`。

## 项目范围

### 包含

- 后端 Admin API。
- 后端 App API。
- 管理端 Web。
- Uniapp H5。
- MySQL 数据库初始化脚本。
- Docker Compose 部署方案。
- 发版验收自动化脚本。
- 外置 Chrome 页面回归清单。

### 不包含

- 正式 POS 收银台完整业务。
- 第三方支付。
- 第三方物流。
- 多租户 SaaS 计费。
- 分布式调度集群。
- 大规模压测方案。

上述能力可作为后续二期或客户定制扩展。

## 技术选型

- 后端：Spring Boot 3.2、Java 17、MyBatis-Plus、Sa-Token、Redis、MySQL。
- 审批：Warm-Flow。
- 调度：Quartz。
- 管理端：Vue 3、Vite、TypeScript、Element Plus、Pinia、Vue Router。
- 移动端：uni-app、Vue 3、Vite、TypeScript。
- 部署：Docker Compose、Nginx 网关。

## 交付口径

项目达到交付标准需同时满足：

- 后端、管理端、移动端构建通过。
- Docker 或本地运行模式可访问。
- 自动化发版验收脚本通过。
- 外置 Chrome 可见窗口页面回归通过。
- 文档、部署说明、验收说明完整。
